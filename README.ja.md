# PG CSV Exporter

[English](README.md)

SSH経由でPostgreSQLの1テーブルをPC上のCSVへ保存するツールです。
Windows画面から接続設定、テーブルのプレビュー、列・期間・保存先の選択、
進捗確認、中止を行えます。PostgreSQLのCOPYで生成したCSVを逐次保存し、
ハッシュ・ヘッダー・件数を確認して完成ファイルにします。

## プレビュー版の状態

署名なしのWindows x64ポータブル版です。既存SSH設定を使うCSV出力を
1台のWindows PCで確認しています。別PC、パスワード認証、暗号化秘密鍵、
Windows資格情報マネージャーとの連携は一連の動作を未検証です。
インストーラーと自動更新はありません。初期表示は英語で、日本語に切り替えられます。

## 必要な環境

- Windows 10/11 x64、Microsoft Edge WebView2 Runtime、OpenSSHクライアント。
- SSH接続可能なLinuxサーバーと、サーバー上のPython 3.11以上・psycopg 3。
- 対象テーブルのSELECT権限を持つPostgreSQL接続情報。
- CSV保存に十分な空き容量。表示する容量は標本行による概算です。

サーバーへのソフトウェア導入やSSH鍵の発行・登録は行いません。
アプリ内に新しい接続設定を登録でき、既存のSSH別名も使えます。
設定はアプリ専用で、SSH設定ファイルは編集しません。
新しいホスト鍵を受け入れる前に、信頼できる経路で指紋を照合してください。

## Windows配布版の利用

1. このリポジトリのReleasesからWindows x64のZIPと`.sha256`を取得します。
2. `Get-FileHash .\PG-CSV-Exporter-v0.2.0-preview.2-windows-x64.zip -Algorithm SHA256`
   の結果をチェックサムと照合し、ZIP全体を書込み可能なフォルダーへ展開します。
3. `pgcsv-desktop.exe`と`pgcsv.exe`を同じ場所に置き、`pgcsv-desktop.exe`を起動します。
4. SSH接続、サーバーのPythonパス、DB設定を入力し、両方の接続を確認します。
5. 1テーブルを選び、プレビュー後に列と必要なら期間を指定します。
6. CSV保存先を選択し、出力します。

Windows PCでの実行にRust・Node.js・Pythonは不要です。
起動がブロックされた場合はWindowsのエラーを控えて原因を確認し、
未確認のファイルを動かすために保護機能を無効にしないでください。

## CSVと認証情報

CSVはUTF-8 BOM付き・ヘッダー付きで、DBセッションの時間帯はAsia/Tokyoです。
期間は開始を含み終了を含みません。時間帯を持たない日時は保存値のまま比較します。
行順は保証せず、10行プレビューは出力件数を制限しません。
1回の対象は1テーブルです。任意SQL入力、件数制限、転送再開には対応していません。

DBトランザクションは読取り専用です。転送中に閉じる前には中止してください。
失敗・中止時に未完成CSVで保存先を置換しません。
DBの文字列を保持するため、表計算ソフトが数式として扱う値も含まれ得ます。
信頼できないCSVは数式を有効にせず文字列として取り込んでください。

設定ファイルにパスワードを保存しません。任意の資格情報保存はWindows資格情報
マネージャーを使います。出力データと接続設定は所属組織の規則に従って管理してください。

## ビルドとライセンス

ビルドにはstable Rust、Node.js 22以上、Python 3.11以上、WindowsではMicrosoft C++
Build Toolsが必要です。[英語版のビルド・テスト手順](README.md#build-and-test)を参照してください。
DesktopのビルドはWindowsが対象です。配布前に`scripts/build-public.ps1`でビルドパスを
置換し、生成exeを検査します。CLIの形式は`pgcsv.exe PROFILE.json OUTPUT.csv [--overwrite]`です。
サンプル設定はプレースホルダーを実際の環境へ置き換えて使用してください。

自作部分は[MIT](LICENSE)です。依存ライブラリはそれぞれのライセンスを保持します。
配布ZIPには第三者ライセンス、該当ソースの取得先、Rust標準ライブラリのnoticeを含みます。

プレビューは各値を文字列で表示し、1024文字を超える部分を省略記号で示します。選択列は最大256列で、応答が4 MiBを超える場合は拒否します。この制限でCSV本出力を切り詰めることはありません。
